/* ARCHITECTURE NOTES */

The site is a fully static build - there is no application server and no database:

- A build step calls the dealer management system and writes the whole inventory
  to static JSON under /data (an index for the listing grid plus one file per cart).
- Vite builds the React app; a prerender step then writes a real HTML page for
  /inventory, /financing and every /golfcart/<slug> URL, each with its own title,
  description, canonical URL, Open Graph tags and Product structured data.
- Search, filtering, sorting and pagination all run in the browser against the
  JSON snapshot, so the site stays fast and has no runtime dependencies.
- 404.html is the SPA fallback, so deep links resolve on GitHub Pages.
- Sitemaps, feeds, location data and the AI permission files are regenerated on
  every build, so they never drift from the live inventory.
