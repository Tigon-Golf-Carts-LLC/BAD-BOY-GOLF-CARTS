# Security Policy for Bad Boy Golf Carts

## Vulnerability Reporting

If you discover a security vulnerability in our website or systems, please report it responsibly to our security team at security@badboygolfcarts.com. Please do not publicly disclose the vulnerability until we have had an opportunity to address it.

## Supported Browsers

We support the latest versions of all major browsers. Please ensure your browser is up to date when accessing our website.

## HTTPS

All connections to badboygolfcarts.com are encrypted with HTTPS/TLS 1.2 or higher. Plain HTTP requests are redirected to HTTPS, and the site is served from GitHub Pages with an automatically renewed certificate.

## Security Measures

- Input validation on all user-submitted data
- SQL injection prevention through parameterized queries
- Cross-site scripting (XSS) protection
- Cross-site request forgery (CSRF) token validation
- Secure password storage with proper hashing
- Rate limiting on API endpoints
- Security headers (Content-Security-Policy, X-Frame-Options, etc.)

## Data Protection

We are committed to protecting user data and comply with applicable privacy regulations. For information about how we handle your data, please visit our privacy policy.
